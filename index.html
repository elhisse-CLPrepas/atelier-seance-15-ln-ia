COMPRENDRE · PREMIÈRE PARTIE

Du fait stable à la règle

Ouvrez les six notions puis composez un message avec un gabarit. Changez une valeur et observez ce qui doit rester fidèle à la source.

01 · InvariantQuel fait doit rester vrai ?+

Dans les versions A et C de S14, le journal explique les corrections. Vérifiez cette affirmation dans le journal de S12, puis soulignez-la dans les deux textes.

02 · VariableQu’avez-vous le droit de changer ?+

Vous pouvez modifier l’accroche, le ton ou le format en gardant le sens de la proposition et l’action adressée au même public.

03 · GabaritComment garder une même structure ?+

Réservez trois places nommées : {titre}, {proposition} et {action}. Renseignez chaque valeur puis relisez le message assemblé.

04 · ConditionQue se passe-t-il à la limite ?+

Si la longueur dépasse 400 caractères, la règle affiche « À raccourcir ». À 400 exactement, elle affiche « Longueur acceptable ».

05 · RépétitionQue devient une erreur répétée ?+

Si vous partez d’une promesse inventée, une boucle peut la recopier dans plusieurs formats. Examinez d’abord le fait dans la source.

06 · RelectureQui se prononce sur le sens ?+

Le candidat cite le passage source, corrige le message et explique la décision. Le pilote examine la preuve. Le résultat de longueur porte uniquement sur le nombre de caractères.

Qui propose, mesure et décide ?

Candidat

Choisit un fait, prédit deux résultats, observe le test et défend une correction.

Agent IA

Peut lire les fichiers fictifs autorisés, proposer un plan de tests et chercher un contre-exemple. Il signale ce qui reste à prouver.

Python

Exécute le gabarit, la condition et la répétition. Avec len(texte), il compte les caractères du texte fourni.

Jupyter

Rassemble explications, code et sorties. Le noyau Python exécute les cellules devant les candidats.

Pilote humain

Vérifie la fidélité des affirmations et statue sur la preuve. Toute autorisation de diffusion relève d’une décision distincte.

 QUATRE MISSIONS À COPIER
Confier un plan de tests à un agent
Précisez les fichiers fictifs autorisés, la mission et le point d’arrêt. Distinguez le résultat prévu de celui qui a été exécuté.
Un nouveau rôle pour l’agent de S15
En S13, l’agent relève les faits. En S14, il compare des formulations. Ici, confiez-lui la préparation de cas limites et la recherche d’un contre-exemple. Le candidat annonce son propre pronostic, observe l’exécution et tranche en revenant à la source.
01 · Relire deux versions
Agent lecteur
Lis seulement la trace fictive de S14 et le journal source fournis. Compare A et C corrigée. Rends un tableau avec les colonnes affirmation, passage d’appui, invariant, formulation qui change. Si un fait manque, inscris « à confirmer ». Arrête-toi après le relevé, sans modifier de fichier.
02 · Concevoir des tests
Agent chargé du plan de tests
La règle d’exercice est : pour un message renseigné, si la longueur dépasse 400 caractères, afficher « À raccourcir », sinon « Longueur acceptable ». Propose un essai exactement à 400, un autre à 401 et un texte bref dont le sens doit être confronté à la source. Donne les entrées et les prédictions. Distingue explicitement les prédictions des exécutions observées. Rends le plan et arrête-toi.
03 · Chercher un contre-exemple
Agent contradicteur
Lis la fiche fictive de Samira et le message « Ce guide doublera vos notes. ». Relève l’affirmation principale. Indique ce que le test de longueur peut montrer, puis cherche le passage qui justifierait le gain annoncé. Si ce passage manque, signale-le. Propose une reformulation fidèle et la référence à vérifier. Je prendrai la décision.
04 · Préparer le notebook S16
Assistant de préparation
À partir de ma trace de S15, organise les données dans un tableau « champ, valeur, source ou justification ». Utilise projet, public, besoin, proposition, action et format. Laisse les absences visibles. Recopie la condition et les deux sorties observées sans les inventer. Signale les éléments qui nécessitent encore l’examen du formateur. Rends le tableau ; aucune diffusion.
